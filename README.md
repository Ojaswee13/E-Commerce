E-Commerce

A simple full-stack shopping website made for a college assignment.

Stack: React, Tailwind CSS, Node.js, Express, MongoDB

Features: login and register, product search and filter, cart, orders, reviews, image upload, admin panel

Run it

Backend:

bash
cd backend
npm install
node server.js

Create backend/.env:

PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=any_secret_text

Frontend (new terminal):

bash
cd frontend
npm install
npm run dev
